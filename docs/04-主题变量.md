# 04 · 主题变量（插件可覆盖的公共契约）

> 定稿日期：2026-10-24
> 状态：**契约**。这里的变量名一旦发布不再改名；要加新变量只往末尾加。
> 用法：插件在自己的样式里重定义 `:root` 的这些变量，就能整体换肤，不用碰宿主的任何 class。

---

## 0. 为什么固定这些变量

美化插件之前只能"猜宿主用了什么类名"，宿主改版一次就断一次。

相反，变量是一层稳定的界面：**插件覆盖变量，宿主随便改内部结构，皮肤不坏。**

代价是这些变量从此不能随便改名 —— 所以只挑真正表达"语义"的那批。

---

## 1. 背景（从深到浅）

| 变量 | 语义 | 深色默认 |
|---|---|---|
| `--bg-sunken` | 最底层、凹进去的区域 | `#12152a` |
| `--bg` | 页面底色 | `#171b30` |
| `--bg-soft` | 卡片、次级面板 | `#212745` |
| `--bg-lift` | 浮起的一层（菜单、悬浮条） | `#2a3050` |
| `--bg-hover` | 悬停态 | `#262c4a` |
| `--input-bg` | 输入框底 | `#1a2038` |
| `--panel-bg` | 主面板卡片 | `#212745` |

## 2. 线与描边

| 变量 | 语义 |
|---|---|
| `--line` | 普通分隔线、卡片描边 |
| `--line-strong` | 需要更明显的边界（输入框、选中框） |
| `--panel-line` | 面板外框 |

## 3. 文字（三级）

| 变量 | 语义 | 备注 |
|---|---|---|
| `--text` | 正文、标题 | |
| `--text-dim` | 次要说明、标签 | |
| `--text-faint` | 最弱（时间、单位） | 已按 WCAG 算过对比度，**别再调淡** |

## 4. 主色

| 变量 | 语义 |
|---|---|
| `--accent` | 主色（按钮、选中态、进度） |
| `--accent-strong` | 主色亮部（渐变高光） |
| `--on-accent` | 主色上的文字色 |
| `--accent-soft` | 主色淡背景（弱提示块） |
| `--glow` | 主色光晕 |

## 5. 语义色（成功 / 警告 / 危险）

每个都有三件套：主色、淡背景、描边。

| 组 | 主色 | 淡背景 | 描边 |
|---|---|---|---|
| 成功 | `--ok` | `--ok-soft` | `--ok-line` |
| 警告 | `--warn` | `--warn-soft` | `--warn-line` |
| 危险 | `--danger` | `--danger-soft` | `--danger-line` |

## 6. 结构尺寸

| 变量 | 语义 |
|---|---|
| `--radius` / `--r-sm` / `--r-md` / `--r-lg` / `--r-xs` / `--r-pill` | 圆角阶梯 |
| `--rail` | 侧栏宽度（默认 88px） |
| `--overlay` | 弹窗遮罩色 |
| `--card-shadow` | 卡片投影 |
| `--scrollbar` | 滚动条 |

## 7. 间距与字号

| 组 | 值 |
|---|---|
| 间距 | `--sp-1`(4) / `--sp-2`(8) / `--sp-3`(12) / `--sp-4`(16) / `--sp-5`(24) |
| 字号 | `--fs-xs`(12) / `--fs-sm`(13.5) / `--fs-md`(15) / `--fs-lg`(17) / `--fs-xl`(19) / `--fs-2xl`(23) |

**间距只走 4 的倍数，字号只有这 6 级** —— 插件也请照这个用，别引入 7px、11.5px 这种值（半像素在 100% 缩放下会糊）。

---

## 8. 换肤示例

```css
/* 一个"暗黑科技感"的皮肤插件，只需要覆盖变量 */
:root {
  --bg: #0b0e14;
  --bg-soft: #11151f;
  --bg-lift: #161b26;
  --line: #1f2635;
  --text: #e6ecf5;
  --text-dim: #8b97ab;
  --accent: #4aa8ff;
  --accent-strong: #7cc0ff;
  --on-accent: #04121f;
  --radius: 8px;
}
```

放进插件的 `ui/*.html` 里（`<style>` 是全局生效的），或者 `startup` 层的 HTML 里。

---

## 9. 不要依赖的东西

| 不要依赖 | 原因 |
|---|---|
| 宿主的 class 名（`.rail-btn` `.set-row` 等） | 随时可能重构 |
| DOM 结构（第几个子元素） | 同上 |
| 内联样式值 | 不是契约 |
| `!important` 堆叠 | 覆盖不动时优先用更具体的选择器，别堆 `!important` |

变量没覆盖到的部分改不动，**那说明该加变量**，去提需求，别硬改。

---

## 10. 变更策略

- **新增变量**：只往末尾加，不需要通知
- **改名 / 删除**：不允许（会破坏所有皮肤）—— 真需要时保留旧名做别名，至少跨一个大版本
- **语义变更**（比如 `--text-dim` 从"次要"变成"禁用"）：不允许，这是最隐蔽的破坏
